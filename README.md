# Airbnb Data Analysis
📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Airbnb listing data to uncover insights related to listing prices, room types, neighborhood distribution, and customer review trends. The analysis helps understand Airbnb market behavior and customer preferences using data visualization and statistical exploration techniques.

### 🎯 Objectives
Analyze the distribution of Airbnb listing prices.
Explore the distribution of different room types.
Identify neighborhoods with the highest number of listings.
Understand the relationship between price and room type.
Examine trends in customer reviews over time.

### 📊 Key Findings
1. Listing Price Distribution
Listing prices are distributed across a wide range.
No single price range dominates the dataset.
The KDE curve indicates a relatively even spread of prices.
2. Room Type Distribution
Entire Home/Apartment is the most common room type.
Hotel Room is the least common room type.
3. Neighborhood Analysis
Manhattan, Brooklyn, and Queens have the highest number of listings.
These neighborhoods dominate the Airbnb market in the dataset.
4. Price vs Room Type
Private Rooms, Entire Homes/Apartments, and Shared Rooms have a broad price range.
Hotel Rooms generally show a narrower but relatively higher price range.
5. Review Trends
The number of reviews increased significantly from 2019–2024 compared to 2014–2018.
This suggests growing user engagement and Airbnb platform popularity over time.
